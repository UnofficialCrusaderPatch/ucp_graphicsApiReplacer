# Graphics API Replacer

**Авторы**: TheRedDaemon, gynt

[ucp_graphicsApiReplacer](https://github.com/TheRedDaemon/ucp_graphicsApiReplacer)

Этот модуль заменяет старую систему вывода DirectDraw более современной, использующей DirectX или OpenGL. Он перехватывает создание окна, немногочисленные вызовы DirectDraw и некоторые функции ввода. По сути, модуль выдаёт себя за DirectDraw и предоставляет память, в которой Crusader программно рисует кадры. Результат затем выводится как текстура через DirectX 11 или OpenGL. Ввод мыши подстраивается под изменённое отображение.

Поддержка пока гарантирована только для западных версий Crusader 1.41 и Crusader Extreme 1.41.1-E. Другие, восточные версии 1.41 могут работать. Версии до HD (1.3?) определённо **НЕ** поддерживаются.

### Настройки

Отдельные параметры подробно описаны на вкладке настройки. Общие правила:

- Разрешение в игре задаёт только разрешение отрисовки. Разрешение окна настраивается параметрами модуля.
- Соотношение сторон игры сохраняется. Пустые области окна остаются чёрными и видны на записях, поскольку входят в выводимое изображение.
- При удержании любой из трёх основных кнопок мыши курсор ограничен игровой областью окна.
- Изменение настроек требует перезапуска игры.
